# Edu Habit Tracker 📚🔥

Edu Habit Tracker is a student-focused habit tracking web application designed to help high school, college, and university students build productive academic routines while maintaining healthy balance.

The app allows students to:

* Add study and wellness habits
* Track daily progress
* Monitor completion rates
* Maintain productive routines
* Balance academics, rest, and wellness

---

## Features 🚀

* Personalized student greeting
* Add new habits dynamically
* Habit validation system
* Mark habits as completed
* Delete habits
* Live dashboard statistics
* Completion percentage tracking
* Academic balance section
* Responsive modern UI
* Local storage support for saved names and habits

---

## Technologies Used 💻

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage API

---

## How It Works ⚙️

1. Enter your name to personalize the dashboard
2. Add a habit with:

   * Habit name
   * Target days
   * Category
3. Mark habits as completed
4. Track your overall progress from the dashboard cards

---

## Validation Rules ✅

The application validates:

* Habit name cannot be empty
* Target days must be between 1 and 7
* A category must be selected
